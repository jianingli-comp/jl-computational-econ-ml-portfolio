Data Directory for CS451 Final Project
--------------------------------------

The file `followers.txt` in this directory is an example graph used only for 
demonstration purposes during the learning phase of this project.

Source:
  This dataset is taken from the official Apache Spark GraphX documentation:
  https://spark.apache.org/docs/latest/graphx-programming-guide.html

License:
  The example is provided under the Apache License 2.0, consistent with Spark's 
  open-source licensing terms.

Usage:
  This file is used in GraphXExample.scala to verify that the GraphX environment 
  and GraphLoader are functioning correctly before running large-scale BA graph 
  experiments.
